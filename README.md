# Personal Portfolio Website

This is a responsive multi-page personal portfolio website created using HTML, CSS, and JavaScript. The project is designed to showcase your professional profile, skills, and projects in an interactive and visually appealing way.

## Features

- Home page with introduction and call-to-action buttons
- About page with bio, education, and skills (using progress bars)
- Projects page displaying multiple projects with images and live links
- Contact page with a working contact form and social media links
- Fully responsive layout using CSS Flexbox and Grid
- Smooth transitions, hover effects, and animations

## Pages Included

- `index.html` – Home page
- `about.html` – About me page
- `projects.html` – Projects showcase
- `contact.html` – Contact form and social links
- `index.css` – Main stylesheet for layout and styling in index.html
- `about.css` – Main stylesheet for layout and styling in about.html
- `projects.css` – Main stylesheet for layout and styling in projects.html
- `contact.css` – Main stylesheet for layout and styling in contact.html



## How to Run

1. Clone or download this repository
2. Open `index.html` in your browser
3. Navigate using the menu links
